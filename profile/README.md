A ridiculously good alternative to the cloud.
Built by developers for developers

We built Deplo for two reasons. 
The first one is the bill. The second one is that every self-hosted alternative
we tried assumes you enjoy debugging a compose file at midnight. We don't.
So we built the one we wanted to use.

**Our mission** is to make self hosting easier: Same ease of use as the cloud, but with zero vendor lock-in and 100% of ownership of your data.
